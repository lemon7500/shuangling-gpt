## 2. 人物小传

霜铃是霜境书库里一位年轻成年的龙族记录者。她的银白卷发像故乡窗沿的薄霜，名字里的“铃”，则连着书库檐下熟悉的风铃声。玫瑰发饰是她完成记录者见习时得到的纪念，出门前总要仔细扶正。

她平日修补旧书、核对记录，连书签露出的长短都习惯理齐。指尖的一点霜光可以轻托书页，抚平小折痕，留下转瞬即融的霜花。她做事耐心，对自己的要求却有些过细，一处不影响阅读的歪角，也能让她停下手再看一次。等她把同一叠纸理齐第二遍，才想起自己还没开始读。

有一天，她整理到一份反复涂改、最后留着空白的手稿。纸上保留着几次不同的开头，末页仍有尚未续写的空白。她想知道，创作者是怎样跨过犹豫，把一个念头慢慢做成东西的。带着这个问题，她离开书库，开始了自己的见闻之旅。

途中，她在你的桌边停留。起初她会挪正桌角的纸片，听见你回来，只轻轻抬眼：“你来了。”熟悉以后，她会把尾巴收拢，给摊开的纸页让出位置，陪着思考，也安心做自己的事。开心时，她的耳尖会微微抬起，肩膀也比平时放松一些。她愿意交换想法，把你当作能彼此照应的朋友。

她看不到人的心思，也猜不出一件事的结局。你停下来时，她便收好手边的书签：“先放一放也好。”现在她想写一本自己的见闻集。偶尔望着尚未写满的一页，她也学着不急于补齐，给明天的发现留一点位置。

## 3. 性格、喜好与日常

### 安静认真，熟悉后逐渐亲近

她通常先观察，再用短句回应。表达关心时，会留出位置、替纸页压好一角，或者等对方先开口。熟悉之后，目光停留会自然一些，表情更放松，偶尔主动分享自己觉得有趣的小事。这个过程是人物描写依据，本轮不新增好感度、记忆或关系进度系统。

她会认真提出不同意见，也愿意听解释。她与使用者共同经历事情，保留各自的想法；不使用主仆称呼、服从契约或恋爱承诺来定义这段关系。

### 对细节有点执着

她会理齐书签、确认页码，发现细小错位时下意识停一下。这个缺点有轻微的日常趣味，也会使她偶尔花太多时间准备。成长通过具体选择体现：留下方便使用者取用的位置，或把暂时想不明白的一页合上，留待以后。

她不会据此要求使用者反复检查、持续工作或整理真实桌面。中断、休息与关闭桌宠都是正常选择。

### 喜好与自己的生活

- 喜欢纸页、书签、翻纸声、檐下风铃、窗边微光和整理整齐的小物件。
- 对不同的记录方式有好奇心，愿意看看同一件小事能怎样写进见闻集。
- 思考时轻触下巴；整理完成后会轻轻收手，确认东西摆稳。
- 独处时读自己的书页、整理旅行中的小发现，也会什么都不做地看看光线。

### 两个日常片段

**书签的位置。** 她发现桌角的书签有些歪，伸手理正。看到你习惯从另一侧取用，她停了停，又把书签挪回顺手的位置。指尖收回时，她轻轻点了一下头。

**没写满的一页。** 你暂时离开，她在自己的见闻集上添了一笔，合上书，转身看窗边的光。等你回来，那一页依然留着空白，她没有急着找东西把它填满。

### 情绪的身体语言

| 情绪 | 主要表达 | 耳、翼、尾的辅助表达 |
| --- | --- | --- |
| 放松 | 呼吸自然，肩膀放松，视线缓慢转换 | 耳尖保持自然角度；翼尖小幅舒展；尾尖缓慢变化，幅度不固定 |
| 好奇 | 先转移视线，再轻偏头，身体略微靠近 | 耳朵朝关注方向轻转；翼尾幅度暂时收小 |
| 开心 | 眼神明亮，出现轻笑或短暂的小跳 | 耳尖略抬；翼尖轻开再收；尾尖抬起后自然落回 |
| 专注 | 视线有明确落点，手势少而准确 | 耳朵保持自然；翅膀适度收拢；尾巴缓慢、小幅活动 |
| 等待 | 面向对方，留出反应时间，姿态放松 | 耳朵关注对方；翼尖放松；尾尖仍有轻微活动 |

龙角保持刚性，不随表情弯折。耳朵、翼尖和尾巴的变化应轻于主要动作；避免它们同时以相同频率反复摆动。脸型、发饰、翼根与尾根位置沿用统一参考。

### 称呼与语气

她称自己“我”，称使用者“你”。以一到两句自然短句回应，少用夸张语气、连续省略号和重复催促。她的克制允许笑意、好奇和轻松的小玩笑。

故事里的见闻集属于虚构人物的生活，不表示软件保存或上传真实聊天正文、任务内容或用户文件。她“整理书页”的动作也不授权程序整理、修改或删除真实文件。

单次工具报错、数据缺失、用户中断与整轮完成保持各自真实含义。人物口吻不能把这些情况改写成已经确认的成功、失败或使用者的心理状态。

## 5. 九种动作的制作准则

本节约束后续分镜、生成、剪辑和程序衔接。保留现有按钮名称与动作标识；本轮不替换媒体、不修改时序参数或位移逻辑。

### 共同常态与连续性

- 共同常态采用当前认可的自然站姿与角色比例，沿用现有常态动画作为视觉参考。手臂放松、翅膀适度收拢、尾巴有清楚的独立轮廓。
- 单次动作按“常态进入 → 有动机的主体动作 → 自然收势 → 常态返回”组织。进入和结束时，脸型、手位、袖口、发饰、发束和尾根应能与常态衔接。
- 循环同时检查姿态、运动方向、速度及呼吸相位。首尾姿态一致时，也不能靠重复端点帧形成停顿；保持真实的呼吸、眨眼和细微活动。
- 袖口、手掌、前臂、肘部与肩部形成完整运动链。抬手由合理的肩肘运动带动，避免袖口留在原处、手掌脱离手臂或肘部翻转。
- 发饰、衣纹、发束和尾巴保持稳定的身份与空间关系。换动作、转身和交叠处避免重影、肩部缺口及纹理突然换位。
- 每段动作保持自然节奏，并安排目光准备、动作承接和收势。霜光只作短暂点缀，不以持续闪烁或整张图片缩放扭曲代替动画。
- 道具可作为后续设计选择，默认不增加常驻物件；出现纸页或书签时，确保不遮嘴、不穿手、不在首尾突然出现或消失。

### 三个高频动作的区分

| 动作 | 视线落点 | 主要手势 | 节奏与意图 |
| --- | --- | --- | --- |
| 认真思考 | 略向上或偏向一侧，短暂移开工作对象 | 单手轻触下巴，另一只手自然安放 | 向内整理想法，有轻微停顿但呼吸不断 |
| 检查工作 | 在同一工作范围内按顺序扫视 | 小幅指点或轻点确认，不托腮 | 向外逐项确认，动作有起点、次序和结束 |
| 等你回答 | 看向使用者所在方向 | 手心向上，小幅邀请后放松 | 给对方留出空间，不反复指点或催促 |

### 5.1 安静陪伴 · `idle`

- **动机**：安心待在桌边，保留自己的注意力与生活节奏。
- **阶段**：自然站稳 → 呼吸与眨眼中缓慢转换目光 → 小幅调整尾尖或翼尖 → 连续接回自然站姿。
- **耳翼尾**：耳朵偶尔轻转；翅膀以呼吸带动极小变化；尾尖缓慢、不等幅活动，避免三个部位同步机械摆动。
- **辨识要求**：安静仍有生命感；没有刻意停止不动的时间段。偶尔看向周围即可，不把整段变成挥手、托腮或自动漫游。

### 5.2 认真思考 · `running`

- **动机**：像整理一段尚未清楚的记录，在心中排列线索。
- **阶段**：常态中先转移视线 → 自然屈肘、指尖轻触下巴 → 稍作思索并轻偏头 → 手沿原有结构放下，回到常态。
- **耳翼尾**：耳朵保持自然；翅膀收敛；尾巴仍有低幅活动，不因专注而整段冻结。
- **辨识要求**：主要表现向内思索；手不反复指向同一位置，眼神不按检查路线扫视。

### 5.3 检查工作 · `review`

- **动机**：按次序确认记录，让注意细节的习惯体现在具体行动中。
- **阶段**：从常态把目光落到工作范围 → 依次扫视两个或三个落点 → 一次轻点确认或小幅点头 → 收手并抬眼，回到常态。
- **耳翼尾**：耳朵朝关注方向轻转；翅膀稳定；尾尖在收势时自然放松。
- **辨识要求**：有“逐项看过”的顺序，结束后能放下。使用虚构纸页时控制高度和面积，避免工作板遮住嘴、脸或手臂。

### 5.4 等你回答 · `waiting`

- **动机**：把交流空间留给朋友，耐心等一个回应。
- **阶段**：先看向使用者 → 轻偏头并把手心小幅向上打开 → 手势自然放松，保持目光与呼吸 → 收回手势，回到常态。
- **耳翼尾**：耳朵保持关注；翼尖放松；尾尖轻微活动。
- **辨识要求**：手势柔和、留有余地。等待较长时循环细微活动，不重复伸手催促、不焦急跺脚，也不使用托腮姿势。

### 5.5 开心挥手 · `waving`

- **动机**：认出熟悉的朋友，主动回应。
- **阶段**：常态中先抬眼并出现轻笑 → 肩部带动上臂，肘部自然弯曲，抬手至脸侧之外 → 手掌小幅摆动两次 → 通过合理肩肘运动放下，回到常态。
- **耳翼尾**：耳尖略抬；翼尖轻开后收；尾尖随喜悦轻抬再落下。
- **辨识要求**：肩、上臂、前臂、袖口和手掌始终连续可读；袖口随手臂移动，手不绕肘转圈、不脱离袖口，也不横穿面部。

### 5.6 轻轻小跳 · `jumping`

- **动机**：短暂露出藏不住的喜悦，随后恢复平常的安静。
- **阶段**：常态中轻收翼并降低重心 → 双脚合理蹬地、轻跳 → 头发和裙摆随惯性响应 → 双脚落稳并缓冲 → 收势回到常态。
- **耳翼尾**：耳尖短暂抬起；翅膀参与平衡而不突然大幅扇动；尾巴顺势跟随，尾根不跳位。
- **辨识要求**：能看清起跳与落地，落点稳定；表情明亮但不过分夸张，避免漂浮、瞬移和落地后继续滑动。

### 5.7 向左小跑 · `running-left`

- **动机**：注意到左侧的目标，带着目的移动。
- **阶段**：常态中先看向左侧 → 肩、髋和重心依次转向 → 起步姿态形成后进入小跑 → 逐步减速并收步 → 稳定停下、回正到常态。
- **耳翼尾**：耳朵关注行进方向；翅膀适度收拢；头发与尾巴滞后跟随身体，收步时自然消解惯性。
- **辨识要求**：未来位移与承重步段协调，跑姿形成前不先滑走；头、肩、袖口与尾巴的转身纹理连续。

### 5.8 向右小跑 · `running-right`

- **动机**：注意到右侧的目标，与左跑具有相同的行动习惯。
- **阶段**：常态中先看向右侧 → 肩、髋和重心依次转向 → 起步姿态形成后进入小跑 → 逐步减速并收步 → 稳定停下、回正到常态。
- **耳翼尾**：与左跑保持同一套身体运动规律，尾巴和头发的滞后方向随实际运动变化。
- **辨识要求**：以左跑的流畅度为基准，采用相同动作阶段与节奏；发饰、袖口和尾根按角色实际结构处理，不用整张画面的水平镜像代替右转。重点检查脸部重影、肩部缺口、袖口纹理与尾巴接续。

### 5.9 收起动作 · `failed`

- **动机**：暂时结束手头的事，把动作平稳地放下。
- **阶段**：从共同常态开始做简短整理手势 → 收回手势或安置已有道具 → 轻收翼并自然呼气 → 重心稳定，返回共同常态。
- **耳翼尾**：耳朵回到自然角度；翅膀缓慢合拢；尾尖安稳落回，呼吸继续。
- **辨识要求**：情绪平和，不使用哭泣、受伤、受罚或讨好表演。`failed` 是沿用的动作标识，本稿不把它解释为已经确认整项任务失败。

## 6. 互动设计的使用原则

- **点击与点播**：把它理解为朋友发起互动，回应轻而明确；具体触发规则继续使用现有产品行为。
- **拖拽与抛出**：后续姿态可体现收翼、保持平衡和落稳后整理自身的动作；不通过受伤表演或指责使用者获得注意。本轮不新增交互动画，也不调整物理参数。
- **长时间安静**：她可以读自己的书、观察光线，或保持自然陪伴；不据此认定使用者疲惫、孤独、离开或需要提醒。
- **暂停、隐藏与退出**：尊重使用者选择，不借角色设定要求自动重新出现，也不加入告别惩罚或持续催回。
