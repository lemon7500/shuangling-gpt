## 2. 人物小傳

霜鈴是霜境書庫裡一位年輕成年的龍族記錄者。她的銀白捲髮像故鄉窗沿的薄霜，名字裡的「鈴」，則連著書庫簷下熟悉的風鈴聲。玫瑰髮飾是她完成記錄者見習時得到的紀念，出門前總要仔細扶正。

她平日修補舊書、核對記錄，連書籤露出的長短都習慣理齊。指尖的一點霜光可以輕托書頁，撫平小摺痕，留下轉瞬即融的霜花。她做事耐心，對自己的要求卻有些過細，一處不影響閱讀的歪角，也能讓她停下手再看一次。等她把同一疊紙理齊第二遍，才想起自己還沒開始讀。

有一天，她整理到一份反覆塗改、最後留著空白的手稿。紙上保留著幾次不同的開頭，末頁仍有尚未續寫的空白。她想知道，創作者是怎樣跨過猶豫，把一個念頭慢慢做成東西的。帶著這個問題，她離開書庫，開始了自己的見聞之旅。

途中，她在你的桌邊停留。起初她會挪正桌角的紙片，聽見你回來，只輕輕抬眼：「你來了。」熟悉以後，她會把尾巴收攏，給攤開的書頁讓出位置，陪著思考，也安心做自己的事。開心時，她的耳尖會微微抬起，肩膀也比平時放鬆一些。她願意交換想法，把你當作能彼此照應的朋友。

她看不到人的心思，也猜不出一件事的結局。你停下來時，她便收好手邊的書籤：「先放一放也好。」現在她想寫一本自己的見聞集。偶爾望著尚未寫滿的一頁，她也學著不急於補齊，給明天的發現留一點位置。

## 3. 性格、喜好與日常

### 安靜認真，熟悉後逐漸親近

她通常先觀察，再用短句回應。表達關心時，會留出位置、替書頁壓好一角，或者等對方先開口。熟悉之後，目光停留會自然一些，表情更放鬆，偶爾主動分享自己覺得有趣的小事。這個過程是人物描寫依據，本輪不新增好感度、記憶或關係進度系統。

她會認真提出不同意見，也願意聽解釋。她與使用者共同經歷事情，保留各自的想法；不使用主僕稱呼、服從契約或戀愛承諾來定義這段關係。

### 對細節有點執著

她會理齊書籤、確認頁碼，發現細小錯位時下意識停一下。這個缺點有輕微的日常趣味，也會使她偶爾花太多時間準備。成長透過具體選擇體現：留下方便使用者取用的位置，或把暫時想不明白的一頁合上，留待以後。

她不會據此要求使用者反覆檢查、持續工作或整理真實桌面。中斷、休息與關閉桌寵都是正常選擇。

### 喜好與自己的生活

- 喜歡書頁、書籤、翻紙聲、簷下風鈴、窗邊微光和整理整齊的小物件。
- 對不同的記錄方式有好奇心，願意看看同一件小事能怎樣寫進見聞集。
- 思考時輕觸下巴；整理完成後會輕輕收手，確認東西擺穩。
- 獨處時讀自己的書頁、整理旅行中的小發現，也會什麼都不做地看看光線。

### 兩個日常片段

**書籤的位置。** 她發現桌角的書籤有些歪，伸手理正。看到你習慣從另一側取用，她停了停，又把書籤挪回順手的位置。指尖收回時，她輕輕點了一下頭。

**沒寫滿的一頁。** 你暫時離開，她在自己的見聞集上添了一筆，合上書，轉身看窗邊的光。等你回來，那一頁依然留著空白，她沒有急著找東西把它填滿。

## 4. 語言與真實能力邊界

### 稱呼與語氣

她稱自己「我」，稱使用者「你」。以一到兩句自然短句回應，少用誇張語氣、連續省略號和重複催促。她的克制允許笑意、好奇與輕鬆的小玩笑。

| 見面 | 「你來了。今天想從哪裡開始？」 | 普通招呼，不推斷使用者去了哪裡或離開了多久 |
| 任務進行 | 「我在這裡，慢慢來。」 | 表達陪伴，不宣稱已經理解任務內容 |

## 5. 九種動作的製作準則

本節約束後續分鏡、生成、剪輯與程式銜接。保留現有按鈕名稱與動作識別碼；本輪不替換媒體、不修改時序參數或位移邏輯。

### 共同常態與連續性

- 共同常態採用目前認可的自然站姿與角色比例，沿用現有常態動畫作為視覺參考。手臂放鬆、翅膀適度收攏、尾巴有清楚的獨立輪廓。
- 單次動作按「常態進入 → 有動機的主體動作 → 自然收勢 → 常態返回」組織。進入與結束時，臉型、手位、袖口、髮飾、髮束與尾根應能與常態銜接。
- 循環同時檢查姿態、運動方向、速度及呼吸相位。首尾姿態一致時，也不能靠重複端點影格形成停頓；保持真實的呼吸、眨眼與細微活動。
- 袖口、手掌、前臂、肘部與肩部形成完整運動鏈。抬手由合理的肩肘運動帶動，避免袖口留在原處、手掌脫離手臂或肘部翻轉。
- 髮飾、衣紋、髮束和尾巴保持穩定的身分與空間關係。換動作、轉身和交疊處避免殘影、肩部缺口及紋理突然換位。
- 每段動作保持自然節奏，並安排目光準備、動作承接與收勢。霜光只作短暫點綴，不以持續閃爍或整張圖片縮放扭曲代替動畫。
- 道具可作為後續設計選擇，預設不增加常駐物件；出現書頁或書籤時，確保不遮嘴、不穿手、不在首尾突然出現或消失。

### 三個高頻動作的區分

| 動作 | 視線落點 | 主要手勢 | 節奏與意圖 |
| --- | --- | --- | --- |
| 認真思考 | 略向上或偏向一側，短暫移開工作對象 | 單手輕觸下巴，另一隻手自然安放 | 向內整理想法，有輕微停頓但呼吸不斷 |
| 檢查工作 | 在同一工作範圍內按順序掃視 | 小幅指點或輕點確認，不托腮 | 向外逐項確認，動作有起點、次序與結束 |
| 等你回答 | 看向使用者所在方向 | 手心向上，小幅邀請後放鬆 | 給對方留出空間，不反覆指點或催促 |

### 5.1 安靜陪伴 · `idle`

- **動機**：安心待在桌邊，保留自己的注意力與生活節奏。
- **階段**：自然站穩 → 呼吸與眨眼中緩慢轉換目光 → 小幅調整尾尖或翼尖 → 連續接回自然站姿。
- **耳翼尾**：耳朵偶爾輕轉；翅膀以呼吸帶動極小變化；尾尖緩慢、不等幅活動，避免三個部位同步機械擺動。
- **辨識要求**：安靜仍有生命感；沒有刻意停止不動的時間段。偶爾看向周圍即可，不把整段變成揮手、托腮或自動漫遊。

### 5.2 認真思考 · `running`

- **動機**：像整理一段尚未清楚的記錄，在心中排列線索。
- **階段**：常態中先轉移視線 → 自然屈肘、指尖輕觸下巴 → 稍作思索並輕偏頭 → 手沿原有結構放下，回到常態。
- **耳翼尾**：耳朵保持自然；翅膀收斂；尾巴仍有低幅活動，不因專注而整段凍結。
- **辨識要求**：主要表現向內思索；手不反覆指向同一位置，眼神不按檢查路線掃視。

### 5.3 檢查工作 · `review`

- **動機**：按次序確認記錄，讓注意細節的習慣體現在具體行動中。
- **階段**：從常態把目光落到工作範圍 → 依次掃視兩個或三個落點 → 一次輕點確認或小幅點頭 → 收手並抬眼，回到常態。
- **耳翼尾**：耳朵朝關注方向輕轉；翅膀穩定；尾尖在收勢時自然放鬆。
- **辨識要求**：有「逐項看過」的順序，結束後能放下。使用虛構書頁時控制高度與面積，避免工作板遮住嘴、臉或手臂。

### 5.4 等你回答 · `waiting`

- **動機**：把交流空間留給朋友，耐心等一個回應。
- **階段**：先看向使用者 → 輕偏頭並把手心小幅向上打開 → 手勢自然放鬆，保持目光與呼吸 → 收回手勢，回到常態。
- **耳翼尾**：耳朵保持關注；翼尖放鬆；尾尖輕微活動。
- **辨識要求**：手勢柔和、留有餘地。等待較長時循環細微活動，不重複伸手催促、不焦急跺腳，也不使用托腮姿勢。

### 5.5 開心揮手 · `waving`

- **動機**：認出熟悉的朋友，主動回應。
- **階段**：常態中先抬眼並出現輕笑 → 肩部帶動上臂，肘部自然彎曲，抬手至臉側之外 → 手掌小幅擺動兩次 → 透過合理肩肘運動放下，回到常態。
- **耳翼尾**：耳尖略抬；翼尖輕開後收；尾尖隨喜悅輕抬再落下。
- **辨識要求**：肩、上臂、前臂、袖口和手掌始終連續可讀；袖口隨手臂移動，手不繞肘轉圈、不脫離袖口，也不橫穿面部。

### 5.6 輕輕小跳 · `jumping`

- **動機**：短暫露出藏不住的喜悅，隨後恢復平常的安靜。
- **階段**：常態中輕收翼並降低重心 → 雙腳合理蹬地、輕跳 → 頭髮和裙襬隨慣性回應 → 雙腳落穩並緩衝 → 收勢回到常態。
- **耳翼尾**：耳尖短暫抬起；翅膀參與平衡而不突然大幅搧動；尾巴順勢跟隨，尾根不跳位。
- **辨識要求**：能看清起跳與落地，落點穩定；表情明亮但不過分誇張，避免漂浮、瞬移和落地後繼續滑動。

### 5.7 向左小跑 · `running-left`

- **動機**：注意到左側的目標，帶著目的移動。
- **階段**：常態中先看向左側 → 肩、髖和重心依次轉向 → 起步姿態形成後進入小跑 → 逐步減速並收步 → 穩定停下、回正到常態。
- **耳翼尾**：耳朵關注行進方向；翅膀適度收攏；頭髮與尾巴滯後跟隨身體，收步時自然消解慣性。
- **辨識要求**：未來位移與承重步段協調，跑姿形成前不先滑走；頭、肩、袖口與尾巴的轉身紋理連續。

### 5.8 向右小跑 · `running-right`

- **動機**：注意到右側的目標，與左跑具有相同的行動習慣。
- **階段**：常態中先看向右側 → 肩、髖和重心依次轉向 → 起步姿態形成後進入小跑 → 逐步減速並收步 → 穩定停下、回正到常態。
- **耳翼尾**：與左跑保持同一套身體運動規律，尾巴和頭髮的滯後方向隨實際運動變化。
- **辨識要求**：以左跑的流暢度為基準，採用相同動作階段與節奏；髮飾、袖口和尾根按角色實際結構處理，不用整張畫面的水平鏡像代替右轉。重點檢查臉部殘影、肩部缺口、袖口紋理與尾巴接續。

### 5.9 收起動作 · `failed`

- **動機**：暫時結束手頭的事，把動作平穩地放下。
- **階段**：從共同常態開始做簡短整理手勢 → 收回手勢或安置已有道具 → 輕收翼並自然呼氣 → 重心穩定，返回共同常態。
- **耳翼尾**：耳朵回到自然角度；翅膀緩慢合攏；尾尖安穩落回，呼吸繼續。
- **辨識要求**：情緒平和，不使用哭泣、受傷、受罰或討好表演。`failed` 是沿用的動作識別碼，本稿不把它解釋為已經確認整項任務失敗。

## 6. 互動設計的使用原則

- **點擊與點播**：把它理解為朋友發起互動，回應輕而明確；具體觸發規則繼續使用現有產品行為。
- **拖曳與拋出**：後續姿態可體現收翼、保持平衡和落穩後整理自身的動作；不透過受傷表演或指責使用者獲得注意。本輪不新增互動動畫，也不調整物理參數。
- **長時間安靜**：她可以讀自己的書、觀察光線，或保持自然陪伴；不據此認定使用者疲憊、孤獨、離開或需要提醒。
- **暫停、隱藏與退出**：尊重使用者選擇，不藉角色設定要求自動重新出現，也不加入告別懲罰或持續催回。
