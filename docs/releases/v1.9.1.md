## English

This release adds frost-white and lilac note-card captions, LXGW WenKai 1.530 and consistent line icons. Six short completion lines rotate without immediate repetition and refer only to a confirmed turn ending. Captions allow more reading time, avoid screen edges and reposition when the font loads; the usage bubble retains its complete layout. The panel and tools continue to support Simplified Chinese, Traditional Chinese and English.

Focus, Shuangling's journal and bookmarks now open and receive focus on their first click, including a cold start. Pressing Shuangling gives an immediate, brief springy response without waiting for animation loading or the longer gesture cooldown. Dragging or cancellation restores the pose, and the same click does not produce a second bounce. Longer companion gestures retain their existing rhythm.

All accepted 1.9.0 animation files, 12 actions and classic variants are retained; no animations were added or regenerated. Ambient company, focus and breaks, Shuangling's journal, **Our days together**, bookmarks, usage and automatic Codex lifecycle remain available. Hiding, pause and manual control continue to take priority.

Requires Windows 10/11 x64 and the installed Codex desktop app. Extract the complete ZIP to a permanent folder writable by your Windows user. Double-click root **`Install plugin.vbs`** (or **`安装Codex插件.vbs`**), then close every Codex window and reopen Codex. No message is required. Node, Electron, runtime dependencies and compiled programs are included; no compilation is needed. GitHub's Source code archives do not include these runtimes.

**Upgrade:** exit Shuangling normally and close all Codex windows. Extract the new version to a new folder, privately back up the old `windows/data`, then copy it into the new folder as `windows/data`. Run the installer from the final new location and reopen Codex. This retains preferences, language, the selected usage chat, journals, shared days and bookmarks. Do not run both installations at once. See the [portable guide](https://github.com/lemon7500/shuangling-gpt/blob/v1.9.1/docs/PORTABLE.md).
