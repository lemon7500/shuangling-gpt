# Codex local plugin marketplace

Use the [project installation instructions](../README.md#快速开始安装插件). Prepare the runtime with the root setup.ps1, then run 安装Codex插件.vbs. The installer generates the private .mcp.json for the final project location before invoking the native Codex plugin CLI. The included .mcp.template.json is a disabled example only.

Plugin ID: `shuangling-gpt@shuangling-local`. Keep the project in place after installation. This source repository is not an official plugin-store listing. See [installation and removal](../docs/INSTALL.md).
